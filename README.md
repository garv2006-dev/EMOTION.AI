# Emotion Classifier Model

An interactive NLP model built with scikit-learn (TF-IDF + Logistic Regression) and deployed using Gradio on Hugging Face Spaces.

## Model Classes
- Anger
- Fear
- Joy
- Love
- Sadness
- Surprise
